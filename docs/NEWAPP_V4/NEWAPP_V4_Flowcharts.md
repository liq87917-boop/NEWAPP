## 2. 登录、组织唯一归属和主设备切换

```mermaid
flowchart TD
  A[打开APP] --> B{已有账号?}
  B -- 否 --> C[手机/微信/NEWAPP ID注册]
  B -- 是 --> D[账号密码/微信/指纹/面容登录]
  C --> E[归并至唯一UserID]
  D --> E
  E --> F{当前是否属于一个有效组织?}
  F -- 否 --> G[个人组织或申请加入企业]
  F -- 是 --> H[检查客户组权限]
  G --> H
  H --> I{设备是否可信?}
  I -- 否 --> J[验证并登记设备]
  I -- 是 --> K[检查主编辑会话]
  J --> K
  K --> L{其他设备正在主编辑?}
  L -- 否 --> M[进入工作台]
  L -- 是 --> N[二次验证与换机提醒]
  N --> O[原子转移主编辑权并撤销旧会话]
  O --> P[旧设备未同步数据隔离恢复]
  O --> M
```

## 3. 询价全流程

```mermaid
flowchart TD
  A[进入询价模块] --> B[加载本业务组有权访问的客户]
  B --> C{客户存在?}
  C -- 否 --> D[快捷新建客户]
  C -- 是 --> E[选择客户]
  D --> E
  E --> F{该客户有本人未提交草稿?}
  F -- 有 --> G[选择恢复某店铺草稿或继续选择店铺]
  F -- 无 --> H[进入店铺搜索页]
  G --> H
  G --> J[恢复询价篮]
  H --> I[初始化不查询店铺, 输入店铺号后搜索]
  I --> K{找到店铺?}
  K -- 否 --> L[带入店铺号并新建]
  K -- 是 --> M[选择店铺]
  L --> M
  M --> N{本店有未提交批次?}
  N -- 是 --> J
  N -- 否 --> O[创建新批次]
  O --> J
  J --> P[手工/复制/历史同款/AI识别新增产品]
  P --> Q[本地保存 + 后台同步]
  Q --> R{继续本店录入?}
  R -- 是 --> P
  R -- 否 --> S{暂存还是提交?}
  S -- 暂存 --> H
  S -- 提交 --> T[检查必填/图片/编号/版本]
  T --> U{服务端确认提交?}
  U -- 否 --> V[保存待提交状态, 恢复同步并核实结果]
  V --> U
  U -- 是 --> W[锁定当前批次, 必要时用更正版本]
  W --> H
```

## 4. 离线存储与可靠同步

```mermaid
flowchart TD
  A[商品录入/拍照/修改] --> B[本地事务持久化]
  B --> C{落盘成功?}
  C -- 否 --> D[提示保存失败, 保留可恢复编辑内容]
  C -- 是 --> E[本地已保存]
  E --> F[生成操作ID并写待同步队列]
  F --> G{联网且设备授权有效?}
  G -- 否 --> H[保留队列与图片, 等待恢复]
  H --> G
  G -- 是 --> I[上传图片/商品操作]
  I --> J[服务端幂等校验 + 版本检查]
  J --> K{结果?}
  K -- 成功 --> L[标记已同步, 不等于已提交]
  K -- 冲突 --> M[进入版本冲突与人工确认]
  K -- 可重试失败 --> N[退避重试并保留原始数据]
  M --> F
  N --> G
```

## 8. 规划与执行约束

- 基础询价永久免费；AI能力收费不能限制原有业务数据使用与导出。
- 统一UserID，一个有效组织归属；多台可信设备登记，同一时间一个服务端主编辑会话。
- 离线状态下无法即时吊销完全断网设备的本地修改，须由授权有效期及重新同步时的冲突恢复控制。
- 免费用户与商家用户之间的数据共享必须经有效授权；私有客户询价绝不可因商家付费默认公开。
- Agent通过业务工具调用，所有工具必须重新执行服务端权限校验；高风险操作保留人工审批。
- 各平台的登录、支付、更新与推送SDK支持及上架规则需要在开发与发布时再次核验。
